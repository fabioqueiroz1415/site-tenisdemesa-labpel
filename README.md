# Sistema de Gestão de Turmas

Este repositório guarda os arquivos das turmas de **Iniciação** e **Aprimoramento**: frequência dos alunos, aulas e plano de ensino.

---

## O que tem aqui?

```
iniciacao/
  frequencia/
    alunos.txt          ← lista de alunos matriculados
    presencas/
      dd-mm-aa.txt      ← presença de cada dia
  ensino/
    plano.md            ← plano de ensino
    aulas/              ← arquivos de aula

aprimoramento/          ← mesma estrutura acima
```

---

## Como funciona a presença?

Cada dia de aula gera um arquivo com o nome da data (ex: `15-04-25.txt`).  
Dentro do arquivo fica o nome de cada aluno que esteve presente, um por linha:

```
Ana Lima
Carlos Souza
Joao de Deus
```

---

## Como usar o sistema (pelo site)?

1. **Presença** – Escolha a turma, confira a data e escreva os nomes dos presentes. Clique em *Enviar presença*.
2. **Alunos** – Adicione ou remova alunos da lista de matriculados.
3. **Ensino** – Acesse o plano de ensino e as aulas disponíveis.
